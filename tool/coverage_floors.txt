# Per-FILE coverage floors. Not a global percentage — a global gate rewards
# tests that assert nothing, and the raw number lies upward.
#
# Only files where a bug is unrecoverable belong here. Each epic adds its own
# at the path it actually uses, in the same PR that creates the file.
#
#   <path-relative-to-repo-root> <minimum-percent>
#
# A listed path that is ABSENT from lcov.info is a FAILURE, never a skip: a
# rename would otherwise silently disarm the floor on exactly the files SPEC
# §10 says a bug is unrecoverable in.
#
# EPIC-04 — the domain engine. A bug in any of these three is a patient taking
# the wrong number of tablets on a Tuesday, which is the definition of
# unrecoverable in SPEC §10.
lib/core/dsns/schedule_generator.dart 100
lib/core/dsns/step_size.dart 100
# 99 rather than 100 for exactly one line: the interpolated MESSAGE of the
# `composition.totalMg == target` assert. That tripwire must never fire, so its
# message can never be evaluated; building the string eagerly to satisfy a
# round number would allocate on every dose in a hot path. Every other line is
# covered — if this drops below 99, a real branch went untested.
lib/core/dsns/tablet_composer.dart 99

# EPIC-05 — the data layer. The database on the phone is the ONLY copy of a
# 780-day plan until EPIC-13 ships an export, so a bug that writes or reads the
# wrong value here is as unrecoverable as a wrong dose.
lib/data/db/converters.dart 100
lib/data/mappers.dart 100
lib/data/settings_repository.dart 100
lib/data/storage_failure.dart 100
# 99 rather than 100 for exactly one line: the `Err` arm of the `suggestStep`
# switch in `_toDoseFrom`. `suggestStep` fails only on an empty strength list
# or a target above the dose, and both are refused before they reach it —
# `savePlan`/`updateStrengths` reject an empty list, and `recordFlare` rejects
# a revert below the target. The arm stays because the switch is exhaustive
# over `Result`, not because any input reaches it. If this drops below 99, a
# real branch went untested.
lib/data/taper_repository.dart 99

# EPIC-03 — the localization edge. `number_formats.dart` is where a ten-fold
# dosing error lives if it lives anywhere: a Persian keyboard emits `1٫5`, and
# a normalizer that folds digits but not separators makes that 15.
# 98 rather than 100 for exactly one line: the catch-all arm of `_reword`'s
# switch. `Milligrams.parse` returns only InvalidDoseFormat, DoseTooPrecise and
# NegativeDose, so the fourth arm exists because the switch is exhaustive over
# the sealed `UnitFailure` family, not because any input reaches it. If this
# drops below 98, a real branch went untested.
lib/l10n/number_formats.dart 98
lib/l10n/date_formats.dart 100
lib/l10n/bidi.dart 100
lib/l10n/app_locales.dart 100
lib/l10n/ckb_material_localizations.dart 100
