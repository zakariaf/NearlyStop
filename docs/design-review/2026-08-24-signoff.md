## The four lenses

- **Floor compliance.** 230 overflow cells green including the composed
  ceiling; every control ≥44pt at 1.0 and 2.0; Taken at ≥88pt; no control
  unnamed in any of the four languages; no focusable node with nothing to say;
  every contrast pair measured against its floor in all four palettes and
  published; every state distinguishable with colour held constant; every
  screen at rest with animations disabled.
- **Identity fidelity.** Daybreak throughout — the warm cream ground, the
  sunrise gradient, the large radii, the soft shadow stack. No Material
  default surfaces anywhere; the one place a Material default had leaked (the
  text-size slider) was caught on a simulator in EPIC-11 and fixed there.
- **Parity.** 24 pairs in `parity/14-design-review/`. Three exact-tier misses
  found and fixed (#06, #07, #08); two differences recorded and kept
  (#11, #12).
- **Motion.** Every screen has zero scheduled frames two seconds after settling
  with animations disabled, and nothing in `lib/` calls `.repeat(`.

## Migration evidence — SPEC §7 "an app update must migrate"

**No on-device upgrade path exists at v1.0.0; first exercised at v1.1.** Per
CONTRACTS §11 the app ships schema **v1**, so there is no earlier artifact
whose upgrade would exercise anything, and a same-schema install-over would
record a false pass on the highest-consequence line in the release gate.

What stands in its place, cited by name rather than re-run by hand:

- `test/data/migration_test.dart` — EPIC-05's `stepByStep` harness against the
  generated v2 fixture. Runs in CI under `--tags migration`.
- `test/data/backup/payload_ladder_test.dart` — EPIC-13's `upgradePayload`
  ladder against a v1-header backup payload, with a synthetic 1 → 2 rung, plus
  a guard that pins the shipped ladder to the schema version so the first bump
  goes red until somebody writes the rung.

From v1.0.1 onward the previous **store** build is the artifact to install
over, and that step returns to the list.

## What is not covered

Four gaps, each named rather than papered over. All four land in EPIC-15's
release gate.

1. **VoiceOver and TalkBack transcripts.** Neither assistive service is
   drivable from this environment. The semantics tree is asserted in
   `test/a11y/semantics_test.dart`; nobody has heard the app.
2. **A profile-mode frame trace.** `docs/perf/schedule-profile.md` records
   what is structurally verified and states plainly that no frame time was
   measured.
3. **Release-build stills with a standardized status bar.** The 66-cell sweep
   is shot from the widget harness; the trade is written into
   `test/a11y/sweep_test.dart`.
4. **The destructive on-device steps** — rotate mid-form, import a backup out
   of Files on both platforms, feed import a truncated file, symbolize a
   crash. The export half of the round trip was run on a simulator and passed;
   the import half needs a picker interaction this environment cannot drive.

## Verdict

**SIGNED OFF** for EPIC-15 to begin, on the condition that the four gaps above
are the release gate's first four items. Nothing in this document may be read
as a pass on any of them.
