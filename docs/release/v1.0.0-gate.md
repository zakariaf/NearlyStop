# v1.0.0 release gate — SPEC §10, ticked against evidence

**Date:** 2026-08-24 · **Commit:** `17e0564` · **Branch:** `epic/15-release`

Every line names a test by file and case, a recorded run, or a section of
EPIC-14's sign-off. **A line with no citation is an untested line and reads as
one.** Nothing here is ticked from memory.

**Verdict: NOT READY TO SHIP.** Four lines are untickable in this environment
and one is deliberately deferred. They are listed as such rather than
approximated, and the reasons are at the bottom.

---

## The ten conditions

### 1. A 52-day step generates correctly and matches the block table byte for byte

**✅ PASS** — `test/core/dsns/dsns_pattern_test.dart`, and the committed golden
vector in `test/core/dsns/golden/` compared byte for byte by
`golden_vector_test.dart`. The block table is asserted structurally
(`runs 52 days`, `the single day leads, and it is the new dose only in blocks
1-6`, `blocks 7 to 11 all have exactly one old day`), not just totalled.

### 2. A property test proves every generated step is 52 days, 26 old / 26 new, for every dose pair

**✅ PASS** — `test/core/dsns/schedule_properties_test.dart`,
`every DSNS step is 52 days, 26/26, with the block table intact`. Seeded fuzz
across dose pairs against an independent oracle, not a handful of examples.

### 3. Tablet composition is correct for every reachable dose, and flags the ones that are not

**✅ PASS** — `test/core/dsns/tablet_composer_test.dart`:
`6.5mg from [5, 1] with halves is 1x5 + 1x1 + half a 1`,
`minimises TOTAL TABLETS before splits`,
`breaks a genuine tie on the largest halved strength`, and — the one that
matters most — `refuses rather than rounding when halves are off`.

CLAUDE.md rule 5 says a dose is never silently rounded. That refusal is
asserted, and the flag reaches the exported PDF too
(`test/features/export/dose_history_document_test.dart`).

### 4. A flare at an arbitrary day regenerates and preserves cumulative history

**✅ PASS** — `test/core/dsns/schedule_generator_test.dart`,
`every day before the flare is identical field for field`. The conservation
half is `test/data/backup/round_trip_test.dart`,
`the cumulative total and the taken count survive exactly` — `==` on integer
hundredths, never `closeTo`.

### 5. Kill the app mid-taper, reopen, and nothing is lost

**⚠️ PARTIAL** — the *code* claim is proven:
`test/features/today/today_persistence_test.dart`,
`a tick survives the container being torn down and rebuilt` and
`a note survives too, and does not become a tick`.

**The on-device force-stop was not run.** It needs the release artifact on real
hardware. See *What was not run*.

### 6. Export produces a PDF a rheumatologist could actually read

**⚠️ PARTIAL** — the PDF is generated, embeds both bundled faces, repeats its
header per page and carries the disclaimer on every page
(`test/features/export/dose_history_pdf_test.dart`,
`test/features/export/export_render_test.dart`). It was **read on screen** in
Kurdish on a simulator during EPIC-13, which found and fixed the tofu-boxes
defect (`docs/design-review/on-device-pass.md`).

**Nobody has printed one.** SPEC §10 says "a rheumatologist could actually
read", and the honest test of that is paper.

One known artefact, recorded not hidden: under RTL the tablets column renders
`2 × 5mg` as `mg5 × 2`. The dose columns a clinician reads are ASCII and
correct. `docs/design-review/2026-08-24-signoff.md`, finding 13.

### 7. Every screen usable at the largest OS text size, in both light and dark

**✅ PASS** — EPIC-14 task 2. 230 cells: six screens × three devices × five
scales × two weights in English, plus German, Persian, Sorani, and the
**composed ceiling** where the in-app slider multiplies an already-maxed OS
scaler. Each cell asserts no overflow *and* that the dose numeral, block title
and day label land inside the thing that draws them — a clipped `Text` reports
no overflow at all.

Also verified beyond the SPEC line: **high contrast**, all four palettes
measured and published in `docs/a11y/contrast-budget.md`.

Five BLOCKERs were found and fixed doing this
(`docs/design-review/2026-08-24-signoff.md`, findings 01–05).

### 8. VoiceOver reads the Today screen as a sentence a person would say

**❌ NOT RUN.** The semantics *tree* is asserted — `test/a11y/semantics_test.dart`
proves no control is unnamed in any of the four languages and the traversal
never stops on a node with nothing to say. **Nobody has heard it.** VoiceOver
and TalkBack are not drivable from this environment.

This is the one line where the automated evidence is furthest from the claim,
and it is stated plainly rather than ticked.

### 9. A database migration test passes from v1.0 schema to v1.1

**⏸️ DEFERRED, and this wording is deliberate:**

> The migration harness is proven against a generated v2 schema fixture
> (EPIC-05) and a v1-header backup payload (EPIC-13); v1.0.0 ships schema v1,
> so there is no on-device upgrade path — first exercised at v1.1.

Named evidence, both green in CI:

- `test/data/migration_test.dart` — EPIC-05's `stepByStep` harness against the
  generated v2 fixture, including `opening a v1 binary against a v2 file fails
  loudly`. Runs under `--tags migration`.
- `test/data/backup/payload_ladder_test.dart` — EPIC-13's `upgradePayload`
  ladder with a synthetic 1 → 2 rung, plus
  `the shipped ladder is empty exactly while the schema is v1`, which turns red
  the day somebody bumps the schema without writing the rung.

An install-over from a same-schema build would be a **false pass** on the
highest-consequence line in this gate, which is why it is not done.

### 10. Zero network calls — verified in airplane mode from a clean install

**⚠️ PARTIAL — three of four layers pass; the run is not done.**

| Layer | Status | Evidence |
|---|---|---|
| Static bans in `lib/` | ✅ | `tool/check_bans.sh`, six must-fail fixtures in `test/tool/check_bans_test.dart` |
| Transitive dependency tree | ✅ | `tool/audit_deps.py`, `test/tool/audit_deps_test.dart` plants a banned package three hops down |
| Runtime — every socket throws | ✅ | `test/policy/no_network_test.dart`, all six screens in two languages, with its own canary |
| Release manifest has no `INTERNET` | ✅ | `test/policy/permissions_test.dart` |
| **Airplane mode, clean release install, whole flow** | ❌ **NOT RUN** | needs a device |

On Android the absent `INTERNET` permission makes a network call *impossible*,
not merely absent — that is the strongest form this proof can take, and it
holds. iOS has no equivalent, so there the airplane-mode run is load-bearing
and it has not happened.

## What was not run, and why

| # | Line | Why | Where it lands |
|---|---|---|---|
| 5 | Force-stop mid-taper on device | Needs the release artifact on real hardware | Release gate, before submission |
| 6 | Print the PDF and read it on paper | Needs a printer and a clinician's eye | Release gate |
| 8 | VoiceOver / TalkBack transcripts | Neither service is drivable here | Release gate |
| 10 | Airplane-mode run from a clean install | Needs a device | Release gate |
| — | Cold-start trace on a floor device | `docs/release/budgets.md` records no number rather than a wrong one | Release gate |

**Submission itself is not attempted**, by instruction: the bundle identifier
is changing and nothing may be uploaded under the current one. A bundle ID is
permanent on both stores once a build is accepted under it.
`docs/release/RELEASING.md` carries the inventory of every place it is written.

## What was proven here that had never run before

- The **first release build this code has ever had**. R8 failed on it —
  Flutter's embedding references Play Core's deferred-components classes.
  Fixed with `-dontwarn` rather than by adding a Play-services dependency for
  a feature nobody uses.
- A **signed, obfuscated `.aab`**, verified signed with the upload key rather
  than the debug key, with its symbol archive split out (13 MB, three ABIs).
- An **iOS release build** carrying `PrivacyInfo.xcprivacy` in the bundle and
  `CFBundleLocalizations` for all four locales, passing the simulator-slice
  check.
- **Size measured** rather than estimated: `docs/release/budgets.md`.
