The idea

Daybreak — light coming up over the horizon

Daybreak is built on one sentence: every dose is one more step toward the morning you are heading for. The ground is warm cream, never white and never clinical; the signature accent is a coral-to-amber sunrise gradient reserved for the single most important thing on each screen; shadows are soft, diffuse and tinted with the same warm hue, so nothing has a hard edge or a cold grey rim. Corners are large — 24px on cards, fully rounded on buttons — because rounded shapes read as friendly rather than as forms to be filled in.

The dark theme is a deep warm plum-brown night that still glows: the same hue family, lowered, never a cold black void. Three signature moves carry the identity — the gradient dose hero with a sunrise arc behind the number, progress drawn as a rising arc, and day state carried by shape (soft filled dot for taken, hollow ring for not ticked) so colour is never doing the work alone.

Audience note: readers are 60–80 and open this app every morning for around 780 days. Nothing may read as clinical, sad or childish. Body text never goes below 17px, and every state has a word next to it.

Motion

Motion in Daybreak is warm and unhurried but never slow enough to be waited on. One easing curve for almost everything: things arrive quickly and settle softly, like light.

--dur-fast 120ms — press feedback, colour changes
--dur-base 220ms — switches, tab changes, chips
--dur-slow 420ms — sheets, theme change, hero arrival
--ease-out cubic-bezier(.22,.85,.34,1)
--ease-in-out cubic-bezier(.65,0,.35,1) — only for things that leave and return
The demo above runs at --dur-slow with --ease-out, and its direction is mirrored in Persian. Nothing in the product bounces, spins or celebrates: the app is opened 780 times and a party animation stops being charming on day 3.
prefers-reduced-motion: every transition duration collapses to 1ms and all animation is switched off — including this page. State still changes instantly and correctly; nothing depends on an animation completing. 
@media (prefers-reduced-motion: reduce){
  *{ animation: none !important; transition-duration: 1ms !important; }
}

RTL rules

The mirror is real, not a hack: there is not a single left/right property in the system. Toggle فارسی above and every component below flips itself.

What mirrors

  • Layout flow — every box uses margin-inline-start, padding-inline-end, inset-inline-start and text-align: start.
  • Directional icons — chevron and arrow (class “mirror”, transform: scaleX(−1)).
  • Progress direction — slider fills from the inline start; the staircase chart is drawn right-to-left in Persian.
  • Switch knob travel — +26px becomes −26px.
  • The sunrise arc — it is a light source with a direction, so it flips with the layout.
  • Tab order — Today sits at the inline start in both languages.

What does not mirror

  • Clock, pill, check, sun, calendar, gear, lock — these have no direction; flipping them makes a clock run backwards.
  • Numerals and units — “۹ میلی‌گرم” keeps its own internal order; the bidi algorithm handles it, we never reverse strings by hand.
  • Latin brand name — “NearlyStop” stays LTR inside Persian sentences, isolated with unicode-bidi.
  • Token names and code — always rendered dir="ltr", left-aligned, even on this page in Persian.

Numerals

Accessibility

Designed as if the reader is not wearing their glasses. These are requirements, not polish — a build that misses one of them is not finished.

Minimum tap target, at true size

44 × 44
56 × 56
64 × 64
44 × 44px is the floor for anything tappable, including icon-only controls and the switch. Buttons are 56px tall and list rows 64px, because the primary user is 60–80 and often taps with a shaky or arthritic hand. Adjacent targets keep at least --s-2 (8px) between them.

Text scaling

Every container is auto-height with wrapping flex rows; no text sits in a fixed-height box. At 200% the card grows, the button grows with it, and nothing clips or truncates — try the buttons. Never use ellipsis on a dose, a date or a state word.
